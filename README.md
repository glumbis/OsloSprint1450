Hackathon workspace for four contributors using AI assistants.

## Current status

The product and technology stack are not selected. AGENTS.md contains the team's working agreement. Codex review is connected. Protected automatic merging requires a clean review of the exact current commit for every team PR. Application build/test checks still need to be added when the stack is selected. See [the hackathon guide](docs/HACKATHON.md).

## Before feature work

1. Agree on the target user, problem, and smallest demo.
2. Choose the stack and deployment target.
3. Create a minimal runnable application and document exact setup/build/test commands.
4. Add meaningful application CI and make its checks required on main.
5. Work in small task branches and PRs. Codex review and protected merging apply to all team PRs.

## Suggested division of work

Assign independent features, each with one owner and its own branch. Agree on shared interfaces before frontend/backend work starts. Keep PRs small. Separate working folders do not isolate shared databases or services.
